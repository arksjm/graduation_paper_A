# Приложение: Калькулятор

## Описание
Go-приложение "Калькулятор" — это простое веб-приложение для сложения чисел с сохранением истории операций в PostgreSQL.

## Функциональность
1. Главная страница (`/`) — приветствие
2. Калькулятор (`/calculator`) — форма для сложения двух чисел
3. История операций — сохраняется в PostgreSQL
4. Метрики (`/metrics`) — для Prometheus

## API
- `GET /` — главная страница
- `GET /calculator` — форма калькулятора
- `POST /calculator` — вычислить сумму (параметры: a, b)
- `GET /metrics` — метрики Prometheus

## База данных
- Таблица: `operation_history`
- Поля: `id`, `operand_a`, `operand_b`, `result`, `operation`, `created_at`

## Проверка
```bash
# Главная страница
curl http://192.168.56.10:8080/

# Калькулятор
curl http://192.168.56.10:8080/calculator

# Вычисление
curl -X POST http://192.168.56.10:8080/calculator -d "a=5&b=3"

# Метрики
curl http://192.168.56.10:8080/metrics

## Pipeline Stages
1. Checkout - загрузка кода
2. Lint - проверка кода
3. Tests - запуск тестов
4. Build - сборка Docker образа
5. Push - публикация в registry
6. Deploy - развёртывание на ВМ
7. Health Check - проверка работоспособности
